# 一栋楼

末日背景下的纯 JavaScript 手机网页生存模拟游戏。所有居民在一栋不断向上生长的大楼中完成食物、教育、医疗、生产、科研和代际繁衍。

## 核心循环

1. 用初始菜园与牧场维持 4 名居民的食物。
2. 根据人才技能花费“解锁费 + 技能门槛 + 科研点数”解锁房间。
3. 再支付建造费并安排居民工作，获得商品收入、服务或科研点数。
4. 建医院后才允许生育；满意度决定劳动意愿与生育概率。
5. 居民衰老、生病、退休和死亡，目标是让文明延续尽可能多代。

## 本地运行与 GitHub Pages

项目无构建依赖，可直接打开 `index.html`，或运行任意静态服务器。GitHub 仓库 Settings → Pages → Source 选择 **GitHub Actions**。推送到 `main` 后会自动发布，并将日期与提交号写入页面上的“游戏更新到 vX.Y.Z+日期.提交号”，因此每次线上更新都有可核对的版本。

AI 权重位于 `ai/weights.json`。后续本地训练器导出同结构文件并提交到仓库，即可随 GitHub Pages 部署同步到线上。

## 推荐补充的系统

- 岗位排班与技能成长：房间不是建完即生效，需要适合的人上岗。
- 能源、供暖、供水、垃圾和氧气：作为中期资源网络，不宜在开局一起压给玩家。
- 家庭与遗传：关系、婚配、孩子教育路线及代际特质。
- 灾害预警与建筑损伤：让外界灾害成为需要准备的事件，而不只是随机扣数。
- 明确失败态与传承档案：无人存活即结束，并记录代数、最高人口和关键事件。
- 房间升级树：每类房间 3 级，每级需要对应科研分支与专业人才。
